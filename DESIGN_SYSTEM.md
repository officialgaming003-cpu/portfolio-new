# VITE + REACT + TAILWIND CSS SETUP

## Website Portfolio CMS - UI/UX Reference

UI/UX Reference dari Aditdev.ID

### Tujuan Desain
Mengambil inspirasi dari gaya desain dan pengalaman pengguna, bukan menyalin identitas merek.

### Karakter Desain yang Diinginkan
- ✅ Full-width modern layout
- ✅ Hero section dengan headline besar dan call-to-action
- ✅ Animasi halus dan profesional
- ✅ Navbar transparan yang berubah saat di-scroll
- ✅ Card dengan sudut membulat dan bayangan lembut
- ✅ Kombinasi warna gelap dan terang yang elegan
- ✅ Glassmorphism ringan
- ✅ Typography modern dan mudah dibaca
- ✅ White space yang lega
- ✅ Section Services, Portfolio, Blog, Testimonial, FAQ, dan Contact
- ✅ Responsive di desktop, tablet, dan mobile
- ✅ Performa tinggi dan SEO-friendly

### ⚠️ PENTING - Tidak Boleh Disalin
- ❌ Logo dari Aditdev.ID
- ❌ Nama brand Aditdev.ID
- ❌ Aset, ikon, ilustrasi
- ❌ Foto atau teks dari Aditdev.ID

### ✅ Apa yang Kami Lakukan
Buat desain orisinal yang memberikan nuansa dan kualitas visual serupa, tetapi tetap memiliki identitas sendiri.

## 🛠️ Tech Stack

### Frontend
- **Vite** - Build tool
- **React 18** - UI Library
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Router DOM** - Client-side routing

### Development
- **Node.js** - JavaScript runtime
- **npm** - Package manager
- **Termux** - Terminal emulator untuk Android

## 🎨 Design System

### Colors
- Primary: Blue (`#3b82f6`)
- Secondary: Purple (`#8b5cf6`)
- Background: White/Gray
- Text: Dark gray (`#1f2937`)

### Typography
- Font: Segoe UI, Tahoma, Geneva
- H1: 4xl - 7xl (hero)
- H2: 3xl - 4xl (section titles)
- Body: 16px
- Small: 14px

### Spacing
- Base unit: 4px (Tailwind default)
- Section padding: py-20
- Container: max-w-6xl

### Effects
- Shadow: shadow-soft, shadow-medium
- Rounded: rounded-lg (12px)
- Animations: smooth transitions
- Glassmorphism: backdrop blur
